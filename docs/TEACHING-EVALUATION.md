# Teaching evaluation and improvement log

This reusable form is intended to help evaluate each tutorial after a workshop, seminar or independent learner trial. It is a planning document: **no teaching session or learner feedback is claimed here**.

## Evidence to capture

- Did learners complete each stated learning outcome? Note observed success or unresolved difficulty.
- Did the notebook or local script run in a clean environment without manual repair?
- Which instructions caused confusion, and at what stage?
- Were dependencies, file paths, interfaces and example outputs reproducible?
- Did the timing fit the lesson, including discussion and troubleshooting?
- Could learners explain why results should not be overinterpreted?
- Did the materials support different skill levels and accessible participation?

## Learner feedback prompts (optional, anonymous)

1. What was the most useful part of the tutorial?
2. Which step was difficult or unclear?
3. Could you reproduce the analysis independently? If not, what prevented you?
4. What prior knowledge did the exercise assume?
5. How would you apply the method to a research question?
6. What should be changed before this exercise is reused?

**Privacy:** Do not commit identifiable learner feedback, attendance records, private student submissions or sensitive research material. Summarise responses at an appropriate level and retain raw feedback only in an authorised environment.
