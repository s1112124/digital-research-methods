# Digital Research Methods

**Dr Eva Ferron** · Digital politics · Computational social science · Research methods education

An evolving collection of **practical, reproducible examples for humanities and social science researchers**. The aim is to connect research questions to data preparation, analysis and interpretable outputs.

**Current status:** One introductory teaching demonstration has been published. It is an educational draft, **not** a previously delivered CDCS/EFI course or a peer-reviewed scholarly output.

## Available tutorial

### [From synthetic platform data to social network analysis](tutorials/social-media-to-network/README.md)

A guided exercise using Python, **pandas** and **matplotlib**. Starting with a *fictional* social-media-style dataset, participants:

1. Check and organise data.
2. Summarise posting activity and engagement.
3. Construct a directed, weighted mentions network.
4. Export an edge list for **Gephi** and consider what network measures can and cannot show.

No platform credentials or live API access are required. The example does **not** contain real social media posts, participant information or doctoral research data.

[Open the tutorial and instructions](tutorials/social-media-to-network/README.md)
